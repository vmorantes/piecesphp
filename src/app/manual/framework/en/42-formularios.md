# Forms

This section brings together the form categories.

## Form categories
<!-- ve: categories-admin-list -->

How to get there: **“Forms” › “Categories”**, in the side menu.

![Form categories](img/categories-admin-list.webp)

The table shows the **Name** of each category. In each row you can **“Edit”**, **“Translate”** or **“Delete”**. At the top are **“New category”** and **“Export current list”**.

## Add and edit a category
<!-- ve: categories-admin-forms-add, categories-admin-forms-edit -->

Click **“New category”**, or **“Edit”** in a category's row; **“Translate”** opens the same form so you can write the name in English. When editing, the **“Languages”** selector chooses which language you are writing in.

![Add and edit a category](img/categories-admin-forms-add.webp)

| Field | Required | What it is for |
| --- | --- | --- |
| Name | Yes | The name of the category. |

Buttons: **“Save”**, **“Cancel”** and, when editing, **“Delete”**.
