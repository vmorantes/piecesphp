# File Manager

This is the explorer for the files the platform stores.

## How to get there

From the side menu: **“File Manager”**.

![How to get there](img/filemanager-admin-filemanager.webp)

## What you can do

You see the folders: **Files**, **Documents (Text Editor)**, **Uploads**, **Temporary** and **Trash**. With the search box in the toolbar, you choose where to search (**“Here”**, **“Volume”** or **“All”**) and what to search by (**“File name”** or **“MIME type”**).
