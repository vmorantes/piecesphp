# Documents

The files shared in the panel, with their type.

## Explore the documents
<!-- ve: documents-admin-explorer -->

How to get there: **“Documents” › “Explore”**, in the side menu.

![Explore the documents](img/documents-admin-explorer.webp)

It is for searching and opening the shared documents. Each document appears on a card with its name, its type and its description. At the top there is a **“Search”** box and at the bottom, the pagination.

On each card, **“Open”** shows the file. If the document has no file, the card says **“No file”**.

## Manage the documents
<!-- ve: documents-admin-list -->

How to get there: **“Documents” › “Manage”**, in the side menu.

![Manage the documents](img/documents-admin-list.webp)

The table shows the **Document name** and its **Actions**. In each row you can **“Edit”**, **“View file”** or **“Delete”**.

At the top are **“Document types”**, **“New document”** and **“Export current list”**.

## Add and edit a document
<!-- ve: documents-admin-forms-add, documents-admin-forms-edit -->

How to get there: click **“New document”**, or **“Edit”** in a document's row.

![Add and edit a document](img/documents-admin-forms-add.webp)

| Field | Required | What it is for |
| --- | --- | --- |
| Type of document | Yes | The type it is classified under. |
| Document name | Yes | The name it shows with in the list. |
| Document | Yes | The file. |
| Description | No | A text that explains the document. |

With **“Change image”** you choose the document's image.

Buttons: **“Save”** and **“Cancel”**. When creating, the file is chosen with **“Add document”**. When editing you also have **“View document”**, **“Change document”** and **“Delete”**.

## Document types
<!-- ve: document-types-admin-list -->

How to get there: the **“Document types”** button in the documents list.

![Document types](img/document-types-admin-list.webp)

The table shows the **Name** of each type. In each row you can **“Edit”**, **“Translate”** or **“Delete”**. At the top are **“New type”** and **“Export current list”**.

### Add and edit a type

Click **“New type”**, or **“Edit”** in a type's row; **“Translate”** opens the same form to write the name in English. When editing, the **“Languages”** selector chooses the language you write in.

| Field | Required | What it is for |
| --- | --- | --- |
| Name | Yes | The name of the type. |

Buttons: **“Save”**, **“Cancel”** and, when editing, **“Delete”**.
