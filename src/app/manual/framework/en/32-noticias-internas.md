# Internal news

The notices that panel users see, by profile and with their dates.

## The news list
<!-- ve: news-admin-list -->

How to get there: **“Internal News”**, in the side menu.

![The news list](img/news-admin-list.webp)

The table shows: **Title**, **Status**, **Start date**, **End date** and **Actions**. In each row you can **“Edit”** or **“Delete”** the news item.

At the top are the buttons **“New news”**, **“Categories”** and **“Export current list”**.

## Add and edit a news item
<!-- ve: news-admin-forms-add, news-admin-forms-edit -->

How to get there: click **“New news”**, or **“Edit”** in a news item's row.

![Add and edit a news item](img/news-admin-forms-add.webp)

| Field | Required | What it is for |
| --- | --- | --- |
| Draft | No | Check it if it is not ready yet. |
| Profile types for which it will be visible | Yes | The user types that will see the news item. |
| Categories | Yes | The category of the news item. |
| Start date | Yes | From when it is shown. |
| End date | Yes | Until when it is shown. |
| Title | Yes | The title of the news item. |
| Content | Yes | The text, with an editor that has bold, italics, lists, links, images and tables. |

Buttons: **“Save”**, **“Cancel”** (goes back to the list) and, when editing, **“Delete”**.

## News categories
<!-- ve: news-category-admin-list -->

How to get there: the **“Categories”** button in the news list.

![News categories](img/news-category-admin-list.webp)

The table shows: **Category**, **Color**, **Image** and **Actions**. In each row you can **“Edit”** or **“Delete”**. At the top are **“New category”** and **“Export current list”**.

### Add and edit a category

| Field | Required | What it is for |
| --- | --- | --- |
| Name | Yes | The name of the category. |
| Color | Yes | The color of the category; the **“Choose color”** button lets you pick it. |

With **“Change image”** you choose the category's icon: it is required when creating. When editing, **“Download / view”** opens the current one. Buttons: **“Save”**, **“Cancel”** and, when editing, **“Delete”**.

When editing, the **“Languages”** selector chooses the language you write in.
