# Your organization

An organization's public profile is what others see about it in the Directory and on the map.

## The public profile

You open it with **“Public profile”**, from the list or the edit screen of an organization; with **“My organization”**, in the menu under your name, if your account has it; or with **“Edit”**, on the profile page of the organization in the Directory. At the top, it says that this is what others see about the organization in the Directory and on the map. It has two tabs: **General data** and **Professional data**. If the organization has no person in charge, the profile cannot be changed: choose one with **“Change”**.

![The public profile](img/my-organization-profile-admin-my-organization-profile.webp)

From here you can:

- **“Account”**: go back to the organization's account data.
- **“View profile”**: opens the organization's profile page.
- **“Change image”**.
- **“Save”** or **“Cancel”**.

Fields of the **General data** tab:

| Field | Required | What it is for |
| :-- | :-- | :-- |
| Name of the organization | Yes | |
| Activity sector - Es | Yes | The sector, in Spanish |
| Activity sector - En | Yes | The sector, in English |
| Email | Yes | |
| LinkedIn link | No | |
| Website link | No | |
| Country | Yes | |
| City | Yes | |
| Phone | No | |

At the end, mark the location on the map.

Fields of the **Professional data** tab:

| Field | Required | What it is for |
| :-- | :-- | :-- |
| Institutions you currently belong to | No | |
| Show the organization profile in the directory and on the map | No | A checkbox to decide whether the profile is shown |
