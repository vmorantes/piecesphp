# Organizations

Here you manage the registered organizations and what is shown about each one.

## The organizations list
<!-- ve: organizations-admin-list -->

You get there from the side menu: **“Management of organizations”**.

![The organizations list](img/organizations-admin-list.webp)

The list has three tabs: **Active**, **Inactive** and **Pending approval**. The table shows code, NIT, organization name, location (country or department and city) and actions.

Each row offers these actions:

- **“Edit”**: opens the organization's account data.
- **“Public profile”**: opens what others see about the organization, so you can edit it.
- **“View profile”**: opens the organization's profile page.
- **“Delete”**.

At the top you have **“Add organization”** and **“Export current list”**.
