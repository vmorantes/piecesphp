# Notifications

The bell in the top bar gathers what concerns you: the notices the system sends you and the internal news that reach
you.

## The bell
<!-- ve: notifications-view -->

How to get there: the **bell** icon, at the top right. The number on it is the notifications you have not read yet; if
there are none, it does not appear.

Clicking it opens a window with:

- four filters, each with its number: **“All”**, **“Internal news”**, **“Unread”** and **“Read”**
  (“Internal news” only appears if the site uses news);
- the list, from newest to oldest. Each notification has an icon according to its type (information, success,
  warning or error), its title, its text and when it arrived. Unread ones look different from read ones;
- **“Mark all as read”**, at the top, when there are unread ones;
- at the bottom, **“Load more”** if there are more, and **“See all”**, which opens the screen with the full list.

Clicking a notification marks it as read and, if it leads somewhere, takes you there. An internal news item opens in a
window with its content.

## All notifications
<!-- ve: notifications-view -->

How to get there: **“See all”**, at the bottom of the bell.

![All notifications](img/notifications-view.webp)

The same list as a full page, with the four filters and **“Mark all as read”**. If there are more, **“Load more”** at
the end brings the next ones.

The ones you have already read are deleted when a new one arrives, if they are more than 90 days old. The ones you have
not read stay until you read them.
