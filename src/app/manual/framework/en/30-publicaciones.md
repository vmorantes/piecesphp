# Publications

Here you manage what is published on the site, with its category and its date.

## The publications list
<!-- ve: publications-admin-list -->

How to get there: **“Publications” › “Publications”**, in the side menu.

![The publications list](img/publications-admin-list.webp)

At the top there are four tabs to filter: **“All”**, **“Published”**, **“Scheduled”** and **“Draft”**.

The table shows these columns: **Title**, **Status**, **Date**, **Author**, **Visits**, **Featured** and **Actions**.

In each row you can:

- **“Edit”** the publication.
- **“View on site”**, to open it as the public sees it.
- **“Delete”** the publication.

At the top there are also the buttons:

- **“New publication”**, to create one.
- **“Categories”**, to go to the publication categories.
- **“Export current list”**.

## Add and edit a publication
<!-- ve: publications-admin-forms-add, publications-admin-forms-edit -->

How to get there: click **“New publication”** in the list, or **“Edit”** in a publication's row.

![Add and edit a publication](img/publications-admin-forms-add.webp)

The form is organized in tabs: **“Basic data”**, **“Images”**, **“Details”**, **“Attachments”** and **“SEO”**.
When you edit a publication you also see one tab per language (**“Spanish”** and **“English”**), to complete each
version of the text.

Fields in **“Basic data”**:

| Field | Required | What it is for |
| --- | --- | --- |
| Main language | Yes | Only when creating: the language in which you write the publication. |
| Name | Yes | The name of the publication. |
| Author | Yes | Who signs it. |
| Date | Yes | The date of the publication. |
| Featured | No | Marks the publication as featured. |
| Draft | No | Check it if it is not ready yet. |
| Content | Yes | The text, with an editor that has bold, italics, lists, links, images and tables. |

More fields in the form:

| Field | Required | What it is for |
| --- | --- | --- |
| Categories | Yes | It is in the **“Details”** tab: the category of the publication. |
| Main image | Yes when creating | It is in the **“Images”** tab. Preferably in .jpg format. |
| Thumbnail image | Yes when creating | It is in the **“Images”** tab. Preferably in .jpg format. |
| Start | No | It is in the **“Details”** tab. Start date. |
| End | No | It is in the **“Details”** tab. End date. |
| Description | No | It is in the **“SEO”** tab. |

Buttons:

- **“Save”**.
- **“Save and translate”**, only when creating.
- **“Cancel”**, to go back to the list.
- **“Delete”**, only when editing.
- **“View on site”**, only when editing.

## Publication categories
<!-- ve: publications-category-admin-list -->

How to get there: **“Publications” › “Categories”**, in the side menu, or the **“Categories”** button in the list.

![Publication categories](img/publications-category-admin-list.webp)

The table shows the **Name** of each category, with the **“Edit”** action. At the top there are **“New category”** and **“Export current list”**.

### Add and edit a category

Click **“New category”** or **“Edit”** in a row.

| Field | Required | What it is for |
| --- | --- | --- |
| Main language | Yes | Only when creating. |
| Name | Yes | The name of the category. |
| Name (Spanish) | Yes | Only when editing. |
| Name (English) | No | Only when editing. |

Buttons: **“Save”**, **“Cancel”** and, when editing, **“Delete”**.
