# Banners and main image

Here you manage the site's banners and main image.

## The banners list
<!-- ve: built-in-banner-admin-list -->

How to get there: **“Banners”**, in the side menu.

![The banners list](img/built-in-banner-admin-list.webp)

One tab, **“All”**. The table shows: **#**, **Title**, **Position**, **Image**, **Mobile image**, **Active date** and **Actions**.

In each row you can:

- **“View the desktop image”**.
- **“Edit”** the banner.
- **“Delete”** the banner.

At the top are **“Add banner”** and **“Export current list”**.

## Add and edit a banner
<!-- ve: built-in-banner-admin-forms-add, built-in-banner-admin-forms-edit -->

How to get there: click **“Add banner”**, or **“Edit”** in a banner's row.

![Add and edit a banner](img/built-in-banner-admin-forms-add.webp)

| Field | Required | What it is for |
| --- | --- | --- |
| Position | No | The order of the banner. |
| Link | No | Where the banner leads. |
| Start | No | From when it is active. |
| End | No | Until when it is active. |
| Name | No | The name of the banner. |
| Content | No | The banner's text, with an editor that has bold, italics, underline, links and colors. |

There are two images, each with its own **“Change image”**: **Image** (required when creating), the desktop one, and **Phone image**, the one for mobile devices. When editing, **“Download / view”** opens the current image.

Buttons: **“Save”** and, when editing, **“Delete”**.

When editing, the **“Languages”** selector chooses the language you write in.

## The main image
<!-- ve: helpers-system-generic-content-admin-forms-home-image -->

How to get there: **“Main image”**, in the side menu.

![The main image](img/helpers-system-generic-content-admin-forms-home-image.webp)

The screen shows the current image. With **“Change image”** you choose another one, with **“Download / view”** you open the current one and with **“Save”** you confirm the change.
